Call the Skill tool with "grilling", then apply the deltas below. The upstream skill is the interview loop; this overlay is how each round is written.

## TLDR

Open every round with a **TLDR**: what is already settled, then what this round is deciding. Refresh it each round. A session-start blurb that never updates is not a TLDR.

## Options

When a question has more than one honest option, list them in **random** order. Shuffle every round. The ➡️ line names the recommendation; list position does not.

When a question has only one honest option, state that recommendation. Skip a choice list. Do not invent fillers so a shuffle has something to shuffle.

## Format

Keep grilling's round shape (❓, ➡️, a horizontal rule between questions). The TLDR sits above the first question. Wait for answers before the next round. Do not act until the user confirms a shared understanding.
